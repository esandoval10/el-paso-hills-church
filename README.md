# El Paso Hills Church — Homepage Prototype

A design-review prototype for El Paso Hills Church, built as a standalone responsive HTML page.

## Preview
To publish on GitHub Pages: open **Settings → Pages** for this repository, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

The expected project URL after deployment is:
https://esandoval10.github.io/el-paso-hills-church/

## Current scope
- Modern, dark navy and champagne-gold design
- Mobile-first layout
- English/Spanish switching
- Mobile navigation and homepage sections

## Important
This is a **concept prototype**, not the official church website and not yet WordPress-integrated.
Photography, church copy, service times, contact details, logo, and ministry information are placeholders or pending confirmation.

Do not publish personal or confidential information in this public repository.

## Next steps
1. Review design with the church.
2. Replace sample copy and photography with approved assets.
